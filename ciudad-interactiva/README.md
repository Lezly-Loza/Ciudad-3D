# Ciudad Interactiva 3D con LWJGL y OpenGL

Actividad práctica de programación gráfica desarrollada en Java con OpenGL moderno y LWJGL 3.

## Requisitos
- Java JDK 17 o superior
- Maven 3.8+

## Instrucciones de Ejecución
Para compilar y correr el simulador, ejecuta en la terminal dentro de la carpeta del proyecto:

```bash
mvn clean compile exec:java
